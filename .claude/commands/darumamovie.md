# カイシャダルマ撮影企画書スライド生成

固定テンプレート `3_Project/会社だるま_IVS/【株式会社FINCHI様用】カイシャダルマ撮影企画書.pptx` を正フォーマットとして、**企業名だけを差し替えた**撮影企画書スライド（.pptx／全3枚・画像/レイアウト/配色/フォントを完全保持）を生成する。

## 手順（必ずこの順で）

1. **企業名を確認する（生成前に必須）**
   - 引数があれば候補として扱う：`$ARGUMENTS`
   - `AskUserQuestion` で、表紙に載せる**正式な企業名の表記**を必ず確認する（例：「株式会社ABC」か「ABC株式会社」か、株式会社の有無、スペース等）。表紙では企業名のうしろに自動で「 御中」が付く。
   - 引数が空なら企業名を尋ねる。
   - **確認が取れるまでスライドを生成しない。**

2. **生成する**
   - 確定した企業名で次を実行：
     ```bash
     python3 "/Users/aoi/Desktop/Bluenote/3_Project/会社だるま_IVS/make_darumamovie.py" "<確定した企業名>"
     ```
   - 出力：`3_Project/会社だるま_IVS/【<企業名>様用】カイシャダルマ撮影企画書.pptx`

3. **確認して報告**
   - 生成物の slide1.xml の `<a:t>` を抽出し、表紙の企業名が正しく入っていること・3枚・画像4点が保持されていることを確認。
   - 出力パスをクリック可能なリンクで報告し、PDF化やGoogleドライブ化が必要か尋ねる。

## メモ
- テンプレートを差し替えたい場合は、新しい完成版pptxを同じファイル名で置き換えるか、`make_darumamovie.py` の `TEMPLATE` / `PLACEHOLDER` を更新する。
- フォーマット仕様の詳細はメモリ `darumamovie-template` を参照。
