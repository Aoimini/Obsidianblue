# 販促コンペ2026（宣伝会議 第18回販促コンペ）

## Summary
[[People/endo-aoi]] が第18回販促コンペ（宣伝会議主催）に応募準備中。2ブランドの企画書を並行制作。PRプランナー／マーケティングプランナー／ストラテジックプランナーの「精鋭3プランナーチーム」合議形式でアイデアをブラッシュアップ（AIを活用した疑似チーム体制と推定）。

## Entries
### 花王エマール（おしゃれ着洗剤）
- お題: 「エマール×おしゃれ着コースで、20代の洗濯に革命を起こすアイデア」
- ブレスト: 第2次ブラッシュアップ版（勝ちパターン8〜11ベース）全10案。★5案: 服の寿命診断（しんだん・しんだ）/ 服の生命保険「エマほけん」/ 縮ませた服 標本展 / HELP ME!タグ
- 設計方針: 物理・店頭・タグ・パッケージで完結（脱アプリ）。既存フォーマット借用＋ダジャレネーミング＋ネガティブ資産の価値転換。
- **最終提出アイデア「EMALサイン」（06-28確定）**: ホテルのドアサインのように、洗濯かごや洗濯機に掛けるタグで洗濯の意思表示を残す。吸盤リング付き3色プレート（「エマール入れてください」「色移り注意」「洗濯宣言（朝洗うよ）」）を洗濯機に設置。家族・同棲中の洗濯トラブル防止→エマール使用促進。
  Source: [[Sources/src-auto-2026-06-28]]

### アース製薬モンダミン プレミアムケア
- 課題①トライアル創出 5案 / 課題②新習慣定着 5案、計10案
- 現在: v3（受賞分析の勝ちパターン8〜11＋11問セルフチェックで全面ブラッシュアップ）
- 核: 歯はお口の25%、残り75%は歯磨きだけではケア不可という「75%の盲点」
- 設計方針: 保険・点検・関所・お守り・当番など社会の「型」を借用。物理・店頭・什器で完結（アプリ/LINE/Web診断は封印）。

### チロルチョコ（小学校の先生を笑顔にする）
- お題: 小学校の先生の「笑顔の総量」を増やすコミュニケーション施策
- ブレスト: 第3版（グランプリ／ゴールド本気狙い）。全案11問セルフチェック全YES通過。全10案: せんせい賞状チロル / せんせい通信簿チロル / おこる前チロル（イエロチロル）/ お礼チロル回覧板 / 保健室の"心チロル" / ごほうび当番チロル / せんせい図鑑チロル / 3年後にとどく時間割チロル / せんせいの「叱り言葉」両替所 / きゅうしょく完食メダチロル
- 設計核: チロル＝「言葉を載せて一粒ずつ手渡せる世界一小さくてかわいい通貨／紙」。個包装に自由印刷＝"紙としての賞状/通信簿"が一粒で成立。
- 設計方針: 「学校の型」（賞状・通信簿・回覧板・保健室・給食当番・図鑑・時間割）にチロルを乗せる。ダジャレ／言い切りタイトル。10インサイト×借用フォーマットで1案1パターンに分散。
  Source: [[Sources/src-auto-2026-06-27]]
- **最終提出アイデア「Ad"de"vent Calendar」（06-28確定）**: 毎月チロルチョコ型カレンダーを学校に配布。毎日日付のチロルをめくるとその日の「お題」（先生3択クイズ・ありがとシャワー・ジェスチャーゲーム等）が出現。クリア数に応じて翌月にチロルチョコをプレゼント（オリジナルパッケージ選択可）。着眼点: 先生は自分を知ってもらう機会が少ない＋団結イベントで笑顔が増える。スライド10枚構成で企画書化。
  Source: [[Sources/src-auto-2026-06-28]]

## Approach
- 受賞作分析DB（勝ち筋7原則＋追加パターン8〜11）と11問セルフチェック（全YES必須）を方法論として確立。
- 過去受賞者（まるやまさん等）のnote記事・企画書も研究。
- グランプリ／ゴールド本気狙い。
- 3ブランド計30案（エマール10＋モンダミン10＋チロルチョコ10）。
