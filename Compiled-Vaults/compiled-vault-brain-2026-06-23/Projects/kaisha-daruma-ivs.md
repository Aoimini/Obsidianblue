# 会社だるま × IVS｜参加者インタビュー動画

## Summary
[[People/endo-aoi]] がSNSプランナーとして関与するプロジェクト。「会社だるま（カイシャダルマ）」ブランドの、IVS会場で撮影する参加者インタビュー縦型ショート動画施策。企画書はv1.0で**代表確認待ち**。

## Goal
一般層への認知・共感（BtoC）→ 公式アカウントのフォロワー獲得。

## Design (source-backed)
- 配信先: Instagram Reels / TikTok / YouTube Shorts（縦型9:16、30〜60秒）
- 構成: フック先出し → 自己紹介 → 参加理由 → マイブーム → **「叶えたいこと」** → だるま目入れ＆記念撮影
- 演出核: だるまの目入れ＝願掛け・決意宣言をクライマックスに。ASMR音設計・ループ構成・テロップ2種で完視聴率/再生数を狙う。
