# Daily Digests

Auto-generated "1日のまとめ" — one file per day. Each digest summarizes:
- the day's Obsidian memos/journal,
- a themed summary of that day's Google searches (themes only, not raw URLs),
- Notion activity (if connected).

Written by the daily pipeline (`_tools/pipeline/`). Source history lives outside git in
`~/.local/share/vaultbrain/`; only the summary lands here.
