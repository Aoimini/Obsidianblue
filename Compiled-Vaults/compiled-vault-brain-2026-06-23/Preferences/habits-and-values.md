# 価値観と日々の習慣

## Core values（日次ノートで反復, 50〜67回）
- **品を保つ**: 「常に品を高く持ち続ける」「品は、何をするかではなく、何をしないかで決まる」。
- **習慣は第二の天性**: 「自分の考えたとおりに生きる。さもなくば、生きたとおりに考えてしまう」。
- **感情と食欲を切り分ける**: 食べたくなったら「今、何を感じているか」を1秒立ち止まって言語化（空腹か／不安・退屈・寂しさか）。
- **優先度の意識**: 「無駄なことはほとんどないが、優先度は存在する」。全部は両立できない前提で時間配分する。

## Daily habits（トラッカー頻出）
- 維持したい: カロリー計算 / 日記 / 読書15分 / 英単語・リスニング / ストレッチ・マッサージ / 運動30分・腹筋・体幹 / 10000歩 / News picks。
- やらないこと（暴食・優柔不断の抑制）: 手持ち無沙汰の間食、帰宅後に2階を彷徨く、1日2回以上の甘いもの、10分以上悩む。

## How agents should apply this
- 提案やスケジュールは「品を保つ」「優先度をつける」という本人の枠組みに沿わせる。
- 食・運動・読書・英語の習慣は継続支援の対象。完璧主義の傾向があるため「70点で着手」を促す（[[Preferences/strengths-finder-gunshi]]）。
