# 強み・働き方の自己モデル（軍師型）

## Core self-model
[[People/endo-aoi]] の自己定義:「複雑なカオスを整理し、人とリソースを『最適配置』して最高効率の仕組みを創り上げる戦略家（軍師型）」。

- 上位資質（StrengthsFinder）: アレンジ／個別化／分析思考／慎重さ／着想（＋戦略性・収集心・学習欲・自我・達成欲）。
- スキル分解: ①全体最適の設計者 ②個を見る解像度 ③学び続ける知性 ④インパクトへの渇望 ⑤リスクを潰す慎重さ ⑥期待値への高解像度（クライアントワークで先回り）。

## 合う環境 / 消耗する環境
| 合う | 消耗する |
|---|---|
| 「なぜ」を問える文化 | 孤立・一人で抱える |
| 人と深く関われる | 返事待ちが続く曖昧さ |
| 成果が可視化される | マニュアル厳守文化 |
| 相談できる存在がいる | 「変えるな」という圧力 |
| 裁量がある | 成果・進捗が見えない |

## モチベーション
- ON: 「あなたにしか見えていない」と言われる／誰かの才能が開花する瞬間／「なぜ」を追求できる／信頼できる人がそばにいる。
- OFF: 全部一人で抱える／「変えるな」圧力／自分のレベル不足を感じる／承認ゼロ。

## 構造的な弱点（要注意パターン）
強みの使いすぎで「引き受けすぎ・抱え込み・アンカー喪失で方向を失う」。対策は「助けを求めることを戦略にする」「アンカーを人ではなく問い/テーマに置く」。
（健康に関わる記述は sensitivity: personal として最小限に扱う。）

## How agents should apply this
- 提案は「なぜ」を添える。曖昧な放置をしない。70点でのアウトプットを後押しする。
- タスクは「完了」でなく「着手」で評価する枠組みを好む。
