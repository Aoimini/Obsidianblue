# ポム & マフィン メニューバーアプリ

`design-guideline.md` の MVP範囲を実装した、macOSメニューバー常駐アプリ (SwiftUI + `MenuBarExtra`)。
MenubarCC のように、Dockや通常ウィンドウではなくメニューバー上の小さなキャラクターで状態を知らせる。

## 起動方法

開発中に動かすだけなら:

```sh
cd PomuMenuBar
swift run
```

`.app` として作ってダブルクリック起動やログイン項目に登録したい場合(Xcode不要):

```sh
cd PomuMenuBar
./build_app.sh
open PomuMenuBar.app
```

`PomuMenuBar.app` を `/Applications` にコピーし、システム設定 > 一般 > ログイン項目 に追加すれば自動起動できる。

## 実装した MVP範囲

1. メニューバーに22x22のミニ・ポムを常駐表示
2. Idle / Searching / Looping / Stuck / Resting の5状態を切り替え可能
   - 通常はマウス/キーボード操作の継続時間から自動判定
   - ポップオーバー下部の「状態プレビュー」で手動確認
3. Looping でメニューバーのポムがぷりぷりダンス、Stuck で点滅
4. クリックでポップオーバーを開き、ポムとマフィン、セリフを表示
5. 「10秒休む」「あと1ページ」「言葉を変える」ボタン
   - 10秒休む: Restingになり、短く休憩状態を表示
   - あと1ページ: Loopingとして、もう一度だけ確認する前提のコメントを出す
   - 言葉を変える: ポム/マフィンのコメントをランダムに更新
6. 検索語や操作内容は保存・送信しない

## 検索ループ判定について

現時点では、ブラウザの検索イベントや履歴を直接読まない。プライバシーと権限を優先し、
システム全体のマウス/キーボード無操作時間だけを読み取る。

自動判定は「休憩なしで操作が続いている時間」を検索・調査のしすぎに近いサインとして扱う。

- 10分以上: Searching
- 20分以上: Looping
- 35分以上: Stuck
- 3分以上無操作: Resting

本当に「検索語が同じか」「不安ワードが続いているか」まで見る場合は、次フェーズで
Chrome拡張やSafari連携を別モジュールとして追加する。
