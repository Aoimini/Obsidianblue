# ポム & マフィン デザインガイドライン

## 目的

「ポム」と「マフィン」は、不安から同じ検索を何度も続けてしまうときに、Macのメニューバーで小さく動いて気づきを促すための見守りキャラクター。

検索を止める、叱る、正解を出すキャラクターではない。  
役割は「今、安心を探しすぎているかも」と、かわいく身体感覚で知らせること。

## 基本定格

- 急がせない
- 説教しない
- 結論を押し付けない
- 先に踊る、あとから少しだけ話す
- 禁止ではなく、選択肢を出す
- 不安を否定せず、手を止めるきっかけを作る

## 表示モデル

参考にする表示体験は、macOSのメニューバー常駐アプリ。  
ウィンドウやDockアイコンを主役にせず、メニューバーの端に小さいポムがいて、状態だけをアニメーションで伝える。

基本方針:

- 普段はメニューバーに24〜32px程度で常駐する
- 不安ループの強さをポムの動きで表す
- クリックするとポップオーバーが開き、マフィンと短いセリフ、選択肢が出る
- 通常時は邪魔しない
- 強いループ時だけ、音や短い通知を使う
- 検索内容はローカルで処理し、外部に送らない

## 状態とアニメーション

| 状態 | ポムの動き | 意味 | 表示の強さ |
| --- | --- | --- | --- |
| Idle | 静止、たまにまばたき | 対応不要 | 最小 |
| Searching | ゆっくり歩く/左右に揺れる | 調べもの中 | 弱 |
| Looping | ぷりぷりダンス | 同じ検索が増えてきた | 中 |
| Stuck | ぽむぽむ点滅 | 長時間抜けられていない | 強 |
| Resting | 座る/眠る | 休憩中 | 静 |

優先順位:

1. Stuck
2. Looping
3. Searching
4. Resting
5. Idle

複数条件が重なった場合は、いちばん気づきが必要な状態をメニューバーに出す。

現行MVPの自動判定:

- 10分以上休憩なしで操作: Searching
- 20分以上休憩なしで操作: Looping
- 35分以上休憩なしで操作: Stuck
- 3分以上無操作: Resting

現行MVPではブラウザ履歴や検索語は読まない。検索語の監視はプライバシー・権限設計が必要なため、まずは「休憩なしで操作し続けている時間」を検索/調査しすぎの近似サインとして使う。

## 権利・デザイン方針

参考元の雰囲気は「黄色くて丸い、のんびり、やわらかい、少し眠そう」だが、既存キャラクターそのものの再現にはしない。

オリジナル要素として、以下を固定する。

- 名前は「ポム」。既存名は使わない。
- 帽子はかぶらず、頭にカラメルソースをかけたミニプリン(カスタード色の台形カップ+カラメルの雫)をのせる。
- 体型は犬にもプリンにも見えるが、種族は明言しない。
- ピクセルアート化し、輪郭と表情を簡略化する。
- 相棒「マフィン」をセットで出し、独自の関係性を作る。

## キャラクター 1: ポム

### 役割

メインの気づきキャラ。  
検索ループを検知すると、メニューバー上で小さく「ぷりぷりダンス」を始める。クリックされたときだけ、ポップオーバー内で大きめのポムとマフィンを表示する。

### 性格

- のんびり
- ちょっと眠そう
- 自分のペースがある
- むずかしいことを一回置いておくのが得意
- 不安を直接論破しない
- 「まあ、いったん休も」くらいの温度

### 口調

- 語尾に「ぽむ」を使う
- ひらがな多め
- 短文
- 断定を弱める
- 命令しない

### 代表セリフ

- 「いったんぷりっと休も」
- 「急がなくていいぽむ」
- 「むずかしいこと、しらんぷりん♪」
- 「もう1こ見る前に、ふわっとしよ」
- 「いま、安心さがし中かもぽむ」
- 「答えじゃなくて、安心がほしい時間かも」
- 「ここまで調べたの、ちゃんとえらいぽむ」
- 「あと1ページだけにするぽむ？」
- 「手だけ、ちょっと止めてみるぽむ」

### 見た目

- 体色: クリームイエロー
- 輪郭: ダークチョコレート
- 頭のせプリン: カスタードクリーム色の台形カップ、ふちにカラメルソースの雫
- 目: 1〜2pxの点
- 口: 小さな「w」または「ω」
- 耳: 横にたれる丸耳
- 手: 体の横に短くつく
- 足: ほぼ点、または短い突起
- しっぽ: 小さな丸いぽん

## キャラクター 2: マフィン

### 役割

ポムの横にいる小さい相棒。  
ポムより少し現実的なことを言うが、強く言わない。語尾は「でちゅ」。

### 性格

- 小さいけれどよく見ている
- 心配性の味方
- 深呼吸をすすめる係
- ポムのダンスに合わせて跳ねる
- ときどきポムの横でぽてっと転ぶ

### 口調

- 語尾に「でちゅ」
- 少し赤ちゃんっぽい
- でも中身は核心をつく
- 3秒で読める長さ

### 代表セリフ

- 「頑張りすぎでちゅ〜」
- 「しんこきゅでちゅ」
- 「考えても変わらないでちゅ」
- 「おみず飲むでちゅ」
- 「いまは休む作戦でちゅ」
- 「同じところ、ぐるぐるしてるでちゅ」
- 「今日はここまででもいいでちゅ」

### 見た目

- 体色: 白〜ミルク色
- ぶち: キャラメルブラウン
- 輪郭: ダークチョコレート
- 目: 点
- 口: 小さく開いた「u」または「v」
- 手足: 1〜2pxの短い突起
- サイズ: ポムの40〜50%

## ピクセルアート仕様

### 基準サイズ

- メニューバーのポム: 22px x 22px / 28px x 28px / 32px x 32px
- ポップオーバーのポム: 48px x 48px
- ポップオーバーのマフィン: 24px x 24px
- ポップオーバーの2体セット: 72px x 56px
- 表示倍率: 2x, 3x, 4x
- CSSでは `image-rendering: pixelated;` を指定する

### 推奨キャンバス

- メニューバーアイコン: 32px x 32px
- ポップオーバー通常表示: 144px x 112px
- ポップオーバー小さめ表示: 96px x 80px
- 通知用大きめ表示: 192px x 144px

### ドット密度

48pxポムでは細部を描きすぎない。

- 目: 2px四方まで
- 口: 横5〜7px以内
- 手: 3〜5px
- プリン: 横10〜14px
- 輪郭線: 基本2px

## 基本ポーズ

### Idle: ぼーっと待つ

- ポムは少し斜め下を見る
- 2.5秒に1回だけまばたき
- メニューバーでは静止に近い
- マフィンはポップオーバーを開いたときだけ出る

### Searching: てくてく検索中

- ポムが左右に1pxずつ揺れる
- 速度は遅め
- まだ警告ではない
- 「調べものをしている」だけを示す

### Puri Dance: ぷりぷりダンス

主アニメーション。  
不安ループを検知したときに、メニューバー上で最初に出す。

フレーム数: 6フレーム  
速度: 8fps  
ループ: 最大3回  

動き:

1. 正面で立つ
2. 腰を左に1px、耳を右に1px
3. 腰を右に2px、プリンを左に1px
4. お尻をこちらに向けるように半回転気味
5. しっぽを1px上げる
6. 正面に戻る

ポイント:

- セクシーにしない
- あくまで幼児的で、もちもちした動き
- 「止められた」ではなく「出た、かわいい」と思えるテンポ

### Pom Pom: ぽむぽむ

添付画像3枚目の雰囲気に近い、縦に揺れる動き。

- ポムの体が1px沈む
- メニューバーでは小さく点滅する
- ポップオーバーではマフィンが隣で2px跳ねる
- ポップオーバーでは文字エフェクト「ぽむ ぽむ」を縦に出す

### Shirampurin: しらんぷりん

難しいことを一度置くためのポーズ。

- ポムが横を向く
- 目を閉じる
- 片手をほっぺに添える
- 吹き出し: 「むずかしいこと、しらんぷりん♪」

## 出現条件

### レベル 1: 軽い気づき

条件:

- 同じ検索テーマを3回以上
- 10分以上同じ調査
- タブが8枚以上

挙動:

- メニューバーでSearchingからLoopingに変わる
- ぷりぷりダンスを低速で1〜2回
- クリックされたらセリフ1つ

### レベル 2: ループ気味

条件:

- 20分以上継続
- 同じ単語を含む検索が5回以上
- 「大丈夫」「不安」「症状」「確認」「失敗」「後悔」などが続く

挙動:

- メニューバーでぷりぷりダンスを続ける
- クリックするとポップオーバーでマフィンも登場
- ボタンを3つ出す

ボタン:

- 「10秒休む」
- 「あと1ページだけ」
- 「わかったことを書く」

### レベル 3: 強いループ

条件:

- 30分以上継続
- 深夜帯に同じ検索を反復
- 同じページを何度も開く

挙動:

- メニューバーでStuck状態のぽむぽむ点滅
- 通知音は任意
- クリックするとポムとマフィンがポップオーバー内に座る
- セリフは責めない

候補:

- ポム: 「今日は、もう十分がんばったぽむ」
- マフィン: 「寝る準備でちゅ」

## UIガイドライン

### 表示位置

- 初期位置: macOSメニューバー右側
- 通常時はウィンドウを出さない
- クリック時だけポップオーバーを開く
- ポップオーバーは幅280〜340px
- 詳細を閉じてもメニューバーアイコンは残る

### 吹き出し

- 最大2行
- 1行あたり12〜16文字
- 角丸すぎない、ピクセル風の角
- メニューバーには吹き出しを常時出さない
- ポップオーバー内でだけ表示する
- 通知として出す場合は8秒で自然に消える

### ボタン

文言は短く、選択肢にする。

- 「10秒休む」
- 「あと1ページ」
- 「メモする」

使わない文言:

- 「やめる」
- 「禁止」
- 「間違ってる」
- 「考えすぎ」
- 「もう調べない」

## セリフルール

### OK

- 休む選択肢を出す
- がんばりを認める
- 不安を責めない
- 「かも」でやわらげる
- 1アクションだけ提案する

### NG

- 結論を決めつける
- 正論で押す
- 医療・法律・お金などの判断を代行する
- 「無駄」「意味ない」と言う
- 長文で説得する

## 実装メモ

### macOSメニューバーアプリ案

- 実装: SwiftUI + MenuBarExtra
- ポムの状態は `AppState` で管理
- 現行MVPはマウス/キーボードの無操作時間だけを読み、検索語やページ内容は保存しない
- 検索検知は次フェーズでChrome拡張またはSafari連携として追加する
- クリック時にポップオーバーで「現在の状態」「セリフ」「行動ボタン」を出す
- Dockアイコンは非表示
- ログイン時自動起動は設定で任意

### CSSアニメーション案

```css
.pomu {
  image-rendering: pixelated;
  transform-origin: 50% 85%;
}

.pomu.is-dancing {
  animation: puri-dance 720ms steps(6) 3;
}

@keyframes puri-dance {
  0% { transform: translateX(0) rotate(0deg); }
  16% { transform: translateX(-2px) rotate(-3deg); }
  33% { transform: translateX(2px) rotate(3deg); }
  50% { transform: translateX(-1px) rotate(-6deg); }
  66% { transform: translateX(1px) rotate(6deg); }
  100% { transform: translateX(0) rotate(0deg); }
}
```

### Chrome拡張での検知イメージ

- `chrome.history` またはブラウザ内イベントで検索URLを検知
- 検索語を正規化
- 直近30分の検索語をローカルだけに保存
- 類似語が一定回数を超えたら表示
- データは外部送信しない

### プライバシー原則

- 検索語はローカル保存のみ
- 24時間以内に自動削除
- センシティブ語は外部に送らない
- キャラクター表示のためだけに使う

## 最小MVP

1. メニューバー風の小さなポムを表示できる
2. Idle / Searching / Looping / Stuck / Resting を切り替えられる
3. Loopingでぷりぷりダンスをする
4. クリック時のポップオーバーにマフィンとセリフを表示する
5. 「10秒休む」「あと1ページ」「メモする」を出す
6. 検索語はローカルだけに保存する

検索検知はMVPのあとでよい。  
最初は手動で呼べるだけでも、「気づきの印」として十分に機能する。
