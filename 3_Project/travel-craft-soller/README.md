# ソリェルのトラム＆サン・バルトメウ教会 ペーパークラフト型紙

マヨルカ島ソリェルで撮った写真（トラム3号車と教会）をもとにした2作品の型紙。
写真の要素（教会のバラ窓・連続アーチ・鐘楼、トラムのオレンジ×ニス塗り木部・
パンタグラフ・「F.C. DE SOLLER S.A.」の社名、左の木と石造りの家・市場テント、
街灯、石畳とレール）を再現。**後方の車は省いてある。**

`build_templates.py` を実行するとSVGを再生成できる（全寸法mm、A4実寸印刷前提）。

## 共通の線の意味
| 線 | 意味 |
|---|---|
| 黒実線 | カット |
| 青破線 | 谷折り |
| 赤一点鎖線 | 山折り（ポップアップのみ） |
| 赤実線 | 差し込みスリット（ジオラマ台座のみ。カッターで切る） |

## 用意するもの
- 厚手のマット紙 or ケント紙（0.2〜0.3mm厚推奨）に**カラー印刷（A4・倍率100%）**
- カッター＋カッターマット、定規、スティックのり

---

## ① レイヤードジオラマ（シート1〜4）

1. シート1〜4を印刷し、各パーツを黒実線でカットする
2. 台座（シート1下）の赤スリット8本をカッターで切る
3. 背景（空）の下ののりしろを谷折りし、台座の**いちばん奥の端**の裏に貼る
4. 各レイヤーの足タブを谷折りし、奥から順にスリットへ差し込む
   - A 教会（奥）→ B 木と家（左）→ C トラム（中央手前）→ D 街灯（右手前)
5. 差し込んだタブは台座裏でテープ留めすると安定する

完成サイズ: 約 幅150 × 奥行き80 × 高さ118mm

## ② ポップアップカード（シート1〜2）

1. ベースカード（横A4）を外周の黒実線でカットする
2. 8本の縦の黒実線をカッターで切る（4つの段差になる）
3. 中央の折り線で谷折りにし、各段差部分は逆に**山折り**で内側へ押し込む
   （青破線=谷折り、赤一点鎖線=山折り。90度開いた時に段が手前へ起き上がる）
4. シート2のパーツ4点を切り出す
5. 各パーツの破線から下（12mm）の**裏面**にのりを付け、ベースカードの
   同じ記号の位置（A教会 / Bトラム / C木と家 / D街灯）に、下端を段の
   谷折り線に合わせて貼る
6. ゆっくり閉じて折りグセをつけたら完成。90度に開いて飾る

構造: 教会が奥の段（30mm手前）、トラムがその手前の段（42mm手前）に
立ち上がる2段ステップフォールド＋左右の小段差（木・街灯）。

---

## 忠実度についてのメモ
手描きベクターによる様式化トレースなので、細部（石の質感、バラ窓のトレサリー
本数など）は簡略化している。より写真に忠実な版が欲しい場合は、深度推定AIで
写真から自動レイヤー分解するスクリプト版に発展できる。
