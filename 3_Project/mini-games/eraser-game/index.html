消しゴム落とし

〜 懐かしの机上バトル 〜

✏️ 📐
遊び方

【基本操作】

自分の消しゴムをマウス（またはタッチ）で引っ張り、弾いて相手の消しゴムを机の外に落とします。

【オリジナル要素】

  • 落書き消し: 机の上の鉛筆汚れ（黒い線）の上を滑ると、汚れが消えて「全力ゲージ」が溜まります。
  • 全力フリック: ゲージが満タンになると、強力な一撃（高威力・消しクズ大量発生）が放てます！
  • 消しクズ: 動くと発生する消しクズの中に入ると摩擦で減速します。防御壁として利用しましょう。
  • 机のギミック: 中央の「回転コンパス」、滑る「液体のり」、障害物になる「えんぴつ」を上手く使いましょう。
