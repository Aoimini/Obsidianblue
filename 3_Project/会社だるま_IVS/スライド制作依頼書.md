> 企画書スライドを制作・再現・修正するための仕様書。デザイナーへの発注、AI/ツールでの再生成にそのまま使えます。
> **資料は2本に分割**：①企業納品動画／②参加者インタビュー動画。

## 3. デザインシステム

### カラーパレット
| 役割 | 用途 | HEX |
|---|---|---|
| INK（深い小豆黒） | 表紙・締めの背景、見出し文字 | `2A1416` |
| CHERRY（だるま赤） | ①企業納品のテーマ色／共通アクセント | `B11226` |
| NAVY（紺） | ②インタビューのテーマ色 ※**塗りのみ。文字には使わない** | `24305E` |
| CREAM（生成り） | 本文スライドの背景 | `FBF6F1` |
| GOLD（目入れ金） | ブランドの目入れアクセント（表紙の目・帯のライン等） | `D89B2B` |
| GRAY（本文） | 本文テキスト | `4A4A4A` |
| BLACK（黒） | ラベル等の文字（旧ネイビー文字はすべて黒に固定） | `000000` |
| MUTE（淡色） | 補足・キャプション | `8A7E78` |

> **テキストカラー規定**：ネイビーは文字に使わない（黒に固定）。色付きラベルは、①資料＝CHERRY、②資料＝BLACK。

### レイアウトルール
- 余白：上下左右 最低 0.5 inch
- 見出し 30pt Bold ／ 小見出し 16–18pt Bold ／ 本文 13–15pt ／ 補足 12–13pt
- カードは白背景＋やわらかいドロップシャドウ（blur 7 / offset 3 / opacity 0.16）
- 装飾下線は使わない（余白と背景色で区切る）
- 中央寄せは見出しのみ。本文・箇条書きは左寄せ
- **構成スライドの行強調はしない**（カット表・質問フローは均一スタイル）

### ビジュアルモチーフ
- 各スライド見出しの左に小さな赤い丸（＝だるまの目）
- 表紙：右に大きな赤い円（だるま）＋黒い目＋金の目（片目入れ）
- テーマ色で①②を色分け（①赤／②紺）し、シリーズ感を出す

## 4. スライド構成（各資料 共通の9枚立て）

| # | スライド | 役割・主な要素 |
|---|---|---|
| 1 | 表紙 | タイトル（動画種別）／だるまモチーフ／ステータス |
| 2 | 目的 | 3カード（①②で内容が異なる。下記5参照） |
| 3 | 基本設計 | 配信先／尺／機材／演出の核／感情設計（5行） |
| 4 | 撮影・編集の型 +α | 音設計(ASMR)／構図・ループ／テロップ2種（3カード） |
| 5 | 構成 | ①＝カット表（7カット）／②＝質問フロー（フック先出し＋5ステップ） |
| 6 | 撮影時のお願い | 「事前のご準備」「当日のお願い」の2パネル（①②で別内容） |
| 7 | 当日オペレーション＆準備物 | オペ／準備物チェックリストの2パネル |
| 8 | 編集・納品 | 尺・テロップ・BGM・納品形式・資産化（5行） |
| 9 | 代表確認事項 | 決め事6項目（2×3、ダーク背景） |

### 5. 「目的」の① ② 違い（重要）
混同しないよう、目的は明確に差別化する。
- **①企業納品**：購入企業（既存顧客）向け。**顧客満足＋法人による二次拡散（BtoB）→ 次の受注**。
  - 納品物としての価値／企業による二次拡散／新規法人への訴求
- **②インタビュー**：一般参加者向け。**一般層への認知・共感（BtoC）→ フォロワー獲得**。
  - 会場の熱量を発信／共感でUGC化／新規フォロワー獲得

## 6. 制作上の注意

- **確定事項**：上記の2分割・配色・各9枚の流れは確定。
- **未確定（プレースホルダー）**：決まり次第差し替え。現状は「要確定」表記。
  - 撮影時間（①「1社あたり 約◯分」／②「1人あたり 約◯分」）
  - マイブーム例「Setlog」の正式名
  - 配信先の優先順位
- **第2弾は対象外**：デスク設置など「オフィス納品編」は今回スコープ外（①スライド2に注記済み）。
- **ブランド素材**：公式ロゴ・指定カラー・指定フォントが支給されたら表紙と締めに反映。

## 7. 納品・展開フロー
1. 各デッキを代表に提示し、スライド9の「決め事」を確定
2. 未確定項目を反映 → 確定版を **PDF書き出し**
3. 協力企業／参加者まわりへ配布

## 参考：再生成について
両デッキは `build_decks.js`（PptxGenJS）で生成。1ファイルで2本同時に出力する。
```bash
cd "3_Project/会社だるま_IVS"
npm install pptxgenjs
node build_decks.js   # → 企業納品動画_企画書.pptx / インタビュー動画_企画書.pptx
```
内容の元データは各資料のmd：`企業納品動画_企画書.md` ／ `インタビュー動画_企画書.md`。
