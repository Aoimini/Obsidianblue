# 四柱推命 項目一覧と算出方法

誰の命式でも同じ手順で出せるように、**項目の定義**と**算出のやり方**だけをまとめたページ。
実際の判定結果は [[四柱推命]] を参照。

---

## 0. 全体の流れ

| 順 | 項目 | 何から出すか |
|---|---|---|
| 1 | **四柱**（年柱・月柱・日柱・時柱） | 万年暦＋生年月日時 |
| 2 | **天干・地支** | 四柱を上下に分解 |
| 3 | **蔵干** | 地支＋節入りからの経過日数 |
| 4 | **通変星** | 日干 × 他の干（天干・蔵干） |
| 5 | **十二運星** | 日干 × 各地支 |
| 6 | **五行バランス** | 天干4つ＋蔵干4つの計8字 |
| 7 | **身旺・身弱** | 日干 × 地支・天干の該当数 |
| 8 | **吉凶の組み合わせ** | 地支どうし・天干どうしの並び |

**すべての基準は「日干（日柱の天干）」**。これが自分自身を表す。日干が決まらないと4以降は一つも出せない。

## 2. 四柱を出す

### 年柱

万年暦の該当年の干支。**立春が年の切り替わり**。

- 1月1日〜立春前に生まれた人 → **前年の干支**を取る
- 立春以降 → その年の干支

### 月柱

**暦の月ではなく、二十四節気の「節入り」で切り替わる**。ここが最頻出の間違いポイント。

- 節入り**前**に生まれた → **前の月の欄**を取る
- 節入り**後**に生まれた → その月の欄

節入り日時は年ごとに違い、時刻まで見る必要がある（例：ある年の芒種が6月5日23:54なら、6月5日12:54生まれは節入り前なので5月の欄）。

### 日柱

万年暦の該当日をそのまま読む。0時切り替わりでよい（子の刻＝23時から翌日扱いとする流派もある）。

### 時柱

**時支**は生まれた時刻から、**時干**は日干との組み合わせから決まる。

| 時刻 | 時支 |
|---|---|
| 23:00〜00:59 | 子 |
| 01:00〜02:59 | 丑 |
| 03:00〜04:59 | 寅 |
| 05:00〜06:59 | 卯 |
| 07:00〜08:59 | 辰 |
| 09:00〜10:59 | 巳 |
| 11:00〜12:59 | 午 |
| 13:00〜14:59 | 未 |
| 15:00〜16:59 | 申 |
| 17:00〜18:59 | 酉 |
| 19:00〜20:59 | 戌 |
| 21:00〜22:59 | 亥 |

時干は「日干の列 × 時刻の行」の交点を干支時刻表から読む。表がない場合は、子の刻の干支を下記から取って順に進める。

| 日干 | 子の刻 |
|---|---|
| 甲・己 | 甲子 |
| 乙・庚 | 丙子 |
| 丙・辛 | 戊子 |
| 丁・壬 | 庚子 |
| 戊・癸 | 壬子 |

> 例：日干が己で11:54生まれ → 甲己の列。子＝甲、丑＝乙、寅＝丙、卯＝丁、辰＝戊、巳＝己、午＝庚 → **庚午**。

### 各柱が表すもの

| 柱 | 領域 |
|---|---|
| 年柱 | 先祖・両親・幼少期・第一印象 |
| 月柱 | 社会運・仕事・お金・人間関係・青年期 |
| 日柱 | 自分自身・配偶者・中年期 |
| 時柱 | 晩年・子ども・財産と健康 |

さらに**天干＝外に見える性質**、**地支＝内側の性質**という縦の分け方がある。

![[命式表の見方.png]]

> 命式表のどのマスが何を意味するかの全体図。年柱0〜18歳／月柱19〜35歳／日柱36〜60歳／時柱61歳以降と、**年齢帯**の対応も入っている。下段は身旺判定の例（日干 丁 を月支 寅・時干 丁 が強めている形）。

## 3. 蔵干

地支の内側に隠れている天干。ひとつの地支に**初蔵（余気）・中蔵（中気）・本蔵（本気）**が最大3つ入っていて、**節入りからの経過日数**でどれを取るかが決まる。

| 地支 | 初蔵 | 中蔵 | 本蔵 |
|---|---|---|---|
| 子 | 壬（〜10日） | － | 癸（11日〜） |
| 丑 | 癸（〜9日） | 辛（〜12日） | 己（13日〜） |
| 寅 | 戊（〜7日） | 丙（〜14日） | 甲（15日〜） |
| 卯 | 甲（〜10日） | － | 乙（11日〜） |
| 辰 | 乙（〜9日） | 癸（〜12日） | 戊（13日〜） |
| 巳 | 戊（〜7日） | 庚（〜14日） | 丙（15日〜） |
| 午 | 丙（〜10日） | 己（11〜20日） | 丁（21日〜） |
| 未 | 丁（〜9日） | 乙（〜12日） | 己（13日〜） |
| 申 | 戊（〜7日） | 壬（〜14日） | 庚（15日〜） |
| 酉 | 庚（〜10日） | － | 辛（11日〜） |
| 戌 | 辛（〜9日） | 丁（〜12日） | 戊（13日〜） |
| 亥 | 戊（〜7日） | 甲（〜14日） | 壬（15日〜） |

![[蔵干表.png]]

> 日数の区切りは書籍・流派で1〜2日ずれることがある。上の表は**書籍の蔵干表に合わせてある**ので、これをそのまま使えばよい。

**経過日数の数え方**：生まれた月の節入り日時から生年月日時までの日数。ひと月まるごと近く経っていれば4柱とも本蔵になることが多い。

## 4. 通変星

日干と他の干との関係を10種類に分類したもの。**天干通変星は外面、地支通変星は内面**を表す。日柱の天干は日干そのものなので空欄になる。

### 算出ルール

日干から見て、相手の干が

| 五行の関係 | 陰陽が同じ | 陰陽が違う |
|---|---|---|
| 同じ五行 | **比肩** | **劫財** |
| 自分が生む（我生） | **食神** | **傷官** |
| 自分が剋す（我剋） | **偏財** | **正財** |
| 自分を剋す（剋我） | **偏官**（七殺） | **正官** |
| 自分を生む（生我） | **偏印** | **印綬**（正印） |

**偏＝陰陽が同じ／正・印綬＝陰陽が違う**と覚えると早い（比肩・劫財だけ逆なので注意）。

- **天干通変星** … 年干・月干・時干をそのまま日干と比べる
- **地支通変星** … 地支そのものではなく、**その柱の蔵干**を日干と比べる

> 例：日干＝己（土・陰）のとき
> 年干 辛（金・陰）→ 土生金＝我生・同陰陽 → **食神**
> 月干 癸（水・陰）→ 土剋水＝我剋・同陰陽 → **偏財**
> 日支の蔵干 壬（水・陽）→ 我剋・異陰陽 → **正財**

### 早見表

ルールで導かなくても、**日干の行 × 相手の干の列**で直接引ける。

### 5グループ

| グループ | 星 | 意味の軸 |
|---|---|---|
| 自星（比劫） | 比肩・劫財 | 自我・仲間・競争 |
| 洩星（食傷） | 食神・傷官 | 表現・アウトプット |
| 財星 | 偏財・正財 | お金・人脈・実利 |
| 官星 | 正官・偏官 | 規律・肩書き・枠組み |
| 印星 | 偏印・印綬 | 学び・知性・インプット |

**印星 → 自星 → 洩星 → 財星 → 官星 → 印星** の順に生じる。どのグループが多いか／ゼロかを見るのが読みの入口。

![[通変星_5グループ.png]]

> グループ名は書籍では自星（自我）・洩星（表現）・財星（財）・官星（実行力）・印星（知性）。他書では比劫・食傷と呼ぶことが多い。

### 各柱の通変星が示す領域

| 位置 | 見るところ |
|---|---|
| 年干 | 引き継いだ傾向・第一印象 |
| 月干 | 適職・仕事のスタイル・金運 |
| 時干 | 晩年・子どもの性格 |
| 年支 | 天から与えられた才能・継承したもの |
| **月支** | **秘めた性質と才能＝元命（命式の中心星）** |
| 日支 | 恋愛傾向・出会い・結婚生活 |
| 時支 | 晩年の健康・子どもからの影響 |

**元命＝月支の通変星**。命式全体の中心として最初に見る。

## 5. 十二運星

日干がその地支の場所でどれだけ力を持つかを、人の一生になぞらえて12段階で表したもの。通変星が「性質」なら、十二運星は**エネルギー量**。

**胎 → 養 → 長生 → 沐浴 → 冠帯 → 建禄（臨官）→ 帝旺 → 衰 → 病 → 死 → 墓 → 絶**

### パワーと象徴する言葉

| パワー | 星 |
|---|---|
| **最強** | 帝旺 |
| **強** | 冠帯・建禄 |
| **中** | 長生・沐浴・墓 |
| **弱** | 胎・養・衰・病・絶 |
| **最弱** | 死 |

| No | 星 | パワー | 象徴 | キャッチ |
|---|---|---|---|---|
| 01 | 胎 | 弱 | 奥手・寡黙・好奇心 | はじめてのことにも動じず、恐れない人 |
| 02 | 養 | 弱 | 依存・愛情・純粋 | 周囲に助けられてコツコツ頑張れる人 |
| 03 | 長生 | 中 | 明朗・快活・友愛 | 心が広く奉仕精神にあふれた人 |
| 04 | 沐浴 | 中 | 妄想・ドリーマー・柔軟 | 純粋で柔軟性があり想像力や感受性も豊かな人 |
| 05 | 冠帯 | 強 | 自我・発展・堅実 | 自我が出つつも、人に親切で可愛がられる人 |
| 06 | 建禄 | 強 | 実行力・行動派・挑戦 | 目標に向かい進む現実派で着実派 |

## 6. 五行バランス

**天干4つ＋蔵干4つ＝計8字**を五行ごとに数える。地支そのものは数えない。

| 五行 | 個数 |
|---|---|
| 木 | |
| 火 | |
| 土 | |
| 金 | |
| 水 | |

見るポイント：

- **最多の五行** … 日干との関係（1の相生相剋）でどのグループが強いかを判断する
- **ゼロの五行** … 対応する通変星グループが命式に無いということ。「無官」「無財」など、その領域が構造的に欠ける
- **相生の流れ** … 木→火→土→金→水と途中で断絶なく繋がっていれば「気の通った」良い構造とされる

### 過多・不足が意味すること

![[五行_過多と不足.png]]

多い五行と欠けている五行を、この表で言葉に変換する。**過多は長所と短所が裏表**（例：土の過多＝現実思考が強い／頑固でマウントしがち）なので、両方まとめて読む。

## 7. 身旺・身弱

日主（自分）のエネルギーが強いか弱いかの判定。身旺なら自力で切り拓く形、身弱なら人や環境の力を借りて伸びる形。**優劣ではない**。

### 手順1：日柱が八専干支か

**甲寅・乙卯・丙午・丁巳・庚申・辛酉・壬子・癸亥**

日柱がこの8つのどれかなら、そこで**身旺確定**。該当しなければ手順2へ。

### 手順2：3項目の該当数を数える

日干の五行を基準に、下の条件に当てはまるものを数える。

| 日干 | ①-1 月支（当旺） | ①-2 月支（次旺） | ② 年・日・時の地支 | ③ 年・日・時の天干 |
|---|---|---|---|---|
| 甲・乙（木） | 寅・卯 | 亥・子 | 寅卯／亥子 | 甲乙／壬癸 |
| 丙・丁（火） | 巳・午 | 寅・卯 | 巳午／寅卯 | 丙丁／甲乙 |
| 戊・己（土） | 丑辰未戌 | 巳・午 | 丑辰未戌／巳午 | 戊己／丙丁 |
| 庚・辛（金） | 申・酉 | 丑辰未戌 | 申酉／丑辰未戌 | 庚辛／戊己 |
| 壬・癸（水） | 亥・子 | 申・酉 | 亥子／申酉 | 壬癸／庚辛 |

![[身旺身弱判定表.png]]

中身は単純で、**当旺＝日干と同じ五行（比劫）**、**次旺＝日干を生む五行（印星）**。つまり「自分を強める字がいくつあるか」を数えている。②は年支・日支・時支をそれぞれ1つとして数え、③も年干・日干・時干をそれぞれ数える。

> 書籍の注記：「自我の働きが強くもなく弱くもない中和状態から、当旺・次旺があると自我を強める作用が働く」。**ゼロが標準で、そこから加点していく**という考え方。

### 手順3：判定

- **①②③のうち2つ以上に該当** → 身旺
- **①がなくても、②③で3つ以上** → 身旺
- それ以外 → 身弱

月支（①）は影響がいちばん大きい柱なので、①を含む身旺は特に強い身旺として読む。

## 8. 吉凶の組み合わせ

命式内の地支どうし・天干どうしの並びを見る。

### 吉

| 種類 | 成立条件 | 組み合わせ（→ 変化する五行） |
|---|---|---|
| **三合** | 地支3つが揃う（2つなら半合） | 子辰申→水局／丑巳酉→金局／寅午戌→火局／卯未亥→木局 |
| **方合** | 地支3つが揃う | 亥子丑→水（北）／寅卯辰→木（東）／巳午未→火（南）／申酉戌→金（西） |
| **干合** | 天干2つの組 | 甲己→土／乙庚→金／丙辛→水／丁壬→木／戊癸→火 |
| **支合** | 地支2つの組（六合） | 子丑→水／亥寅→木／戌卯→木土／酉辰→土金／申巳→金／未午→火 |

**三合＝円に配したとき正三角形（120度）になる3支**、**方合＝同じ季節の3支**。方合は三合や支合より数倍強い吉作用とされる。

![[吉_三合と方合.png]]

![[吉_干合と支合.png]]

> 天干＝頭、地支＝体。支合が「手を取り合う協力・親和」なのに対し、**干合は「一目惚れ・インスピレーション」的な惹かれ合い**。恋愛の相性は干合、結婚・友人・仕事の相性は支合で見るとよい、と書籍にある。

> 吉の組み合わせは**まったく無くても問題ない**。大半の人は無い。

### 凶

| 種類 | 組み合わせ |
|---|---|
| **七沖**（六冲） | 子午／丑未／寅申／卯酉／辰戌／巳亥 |
| **三刑** | 寅巳申（無恩）／丑戌未（持勢）／子卯（無礼） |
| **自刑** | 辰辰／午午／酉酉／亥亥 |
| **六害** | 子未／丑午／寅巳／卯辰／申亥／酉戌 |

凶の強さは **三刑・自刑・七沖 ＞ 六害**。六害は前3つに比べると弱いので、あまり気にしなくてよいとされる。

| 種類 | 読み方 |
|---|---|
| 三刑 | 互いに理解できない、わかり合えない配置。人間関係のトラブル |
| 自刑 | 「自分を剋する」。自暴自棄、または極度の負けず嫌いから人と争う |
| 七沖 | 円の正反対＝敵対関係。特に月支・日支にあると波乱・アクシデント |
| 六害 | 分離と不和。家庭環境の不和、すれ違いや孤独感 |

![[凶_三刑と自刑.png]]

![[凶_七冲と六害.png]]

**成立位置も見る**。隣り合う柱（年-月／月-日／日-時）で成立したものを本来の凶とし、離れた柱（年-日、年-時など）は取らない流派も多い。

> 凶が出ても極端に読まない。五行バランスでどちらが優勢かを合わせて見て、強さの差を加味する。

### 相性（日柱で見る）

自分の日柱を基準に、相手の日干・日支で判定する。

| 判定 | 相手の条件 | 領域 |
|---|---|---|
| 干合 | 自分の日干と干合する日干 | 恋愛の相性が良い |
| 支合 | 自分の日支と支合する日支 | 友だち・仕事の相性が良い |
| 七沖 | 自分の日支と七沖する日支 | 相性が悪い |
