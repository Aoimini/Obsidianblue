# TOEIC 単語カード

Spaced Repetitionプラグイン用のカード。`単語 :: 意味` の1行が1枚のカードになります。
復習はコマンドパレット→「Spaced Repetition: Review flashcards」か、右のリボンアイコンから。
[[単語メモ]]に新しい単語を溜めたら、覚えたいものをここに `::` 形式で移すのがおすすめ。
