# 広告代理店について
参考：https://kashika-20mile.com/dpro/articles/advertising-business-model/#i-3　

### ① ビジネスモデル（どう稼いでいるか）
- 収益は大きく2つ。**メディアからの「コミッション（手数料）」** と **クライアントからの「フィー（報酬）」**。
- 従来のマス広告は **媒体費の一定割合（例：15〜20%）を手数料**として受け取るのが一般的。＝「広告枠を仕入れて売る」モデル。
- ただしデジタル広告は **運用工数に対して手数料が見合わないケースが増加**。
  → **工数ベースのフィー契約**や**成果報酬型**など、稼ぎ方が多様化している（＝"枠売り"から"課題解決の対価"へ）。

### ② 代理店ごとの違い
- **総合広告代理店**：テレビ・新聞・ネットなど**あらゆる媒体を扱い、企画から制作まで一気通貫**。大手が中心（電通・博報堂・ADKなど）。
- **専門広告代理店**：**特定領域に特化**（ネット広告専門、交通広告専門など）。深い専門知識が強み。
- **ハウスエージェンシー**：**特定の事業会社専属**の代理店。親会社の広告をメインに担い、情報の秘匿性・コスト削減に寄与。

# Q＆Aコーナー

### 業界に関して
- 「広告業界は『クライアントの課題解決』が軸としてあると考えている。その手段が、広告よりもコンサル要素が強くなってきている印象がある。」この認識は正しいのかどうか
📝認識は相違ないです。昔はどれだけ面白いものを作れるか、テレビで目立つCMを作れるかが重視されてきたけど、人の目に留まるだけでは行動変容は起こせないし、今は試作に対してどれだけ数字が反映されたかというのが求められてくるので、何かをクリエイティブ制作するというだけではなくて、根本に課題解決できているのか、数字の改善が求めるのかというのはコンサル同様求められているところだと思います。

その上で広告業界としてがプランニングのプロであり、実際に質を落とさずにいいもの面白いものを作れるっていうことは強みだと思うので、課題解決が目的の上で、いいアウトプットを世の中に発信し続けるっていうことが今求められている立ち位置。

- AIに仕事を奪われている実感はあるのか
-  AI の発展や広告主のインハウスが進む中で、総合広告代理店だけが持ち続ける価値とは
📝議事録の作成だったり、簡単なリサーチ、動画制作などクリエイティブでもすごくAIが使えるようになっている実感はある。一方で担当者の好みや、同業他社の動きなどAIに入れられない情報も含めて、人の心を動かすには人間から生み出される発想力が必要。発想力がある人が手段としてAIを使うからこそ、いいものが作れるのであって、すべてがAIに代替されるということはない。
Eハウス化に関しても、予算の縮小によってどんどんクライアント内での政策は進むと思う。しかし、普段の仕事の中でサービスや商品を起点に仕事をしていないMのクライアントさんの課題に対して、手段を日々考えて、クレンドや情報をいち早くインプットしている場所にいるからこそ、冷静な判断や中からは出ないようなアイディアが出ると思う。

異業種同士でのコラボ、特にIPなどとの関連性は、会社間ではどうしてもきっかけが生まれないと思う。

デメリットは、やはり他の社会人と比べてライフスタイルが乱れやすく、ライフワークバランスが取りにくいことです。休日に自分の余白の時間を作りにくかったり、1日の時間が見えにくいクライアントワークのため、製作物が上がってくる時間はコントロールできません。また急な依頼が打ってきたりすることもあり、それに応じて対応していることもあります。

# ES

ESは「書類通過」のためではなく、**面接で話やすくするため**に書く。面接で話したい展開を逆算して仕込む。

**書き方のフロー（例：挫折を30字で）**
1. 自分のキャラクターが伝わりやすいエピソードを決める（例：選手→マネージャーになった話）
2. 一番ウケそうなシーンを考える（例：マネになった経緯、審判資格を取得した理由こと）
3. どんな質問が来れば②を話せるか考える（例：「なんでマネになったの？」「どうして審判をやろうと思ったの」）
4. 質問したくなる/記憶に残る**パワーワード**を仕込む（例：「新しい挑戦をする同期の輝くきっかけを作りたい」「選手じゃないから相談しても分からないかと言われるのが悔しかった」）


- キャッチーな言葉で書くと、面接官が**ピンポイントで面接時に聞きたくなる**
- 強いガクチカは必要ない（GSの田中渓さんも夜勤コンビニバイトの話で内定している）
- **「自分の人間性を相手に納得させるところまでをデザインする」のがESのコツ。**

# ガクチカ

- 大事なのは相手がイメージできるように言語化できるか。
  - 成果物ではなくて、状況に対して「何を課題に感じ」「周りとどう関わり」を持ったかのプロセス
  
- ### ガクチカ比較
- **A（きれいだけど抽象的な言葉）**：「中々試合に出られなかったが、誰より早く来て自主練に取り組む姿をみせたことで、部員や監督からの信頼を勝ち取りピンチバッターの座を掴んだ」
- **B（具体・泥臭い）**：「誰より早く来て自主練の動画を取り、自主練用のSNSに毎日アップし続けアドバイスを積極的に求めに行ったことで"脳筋二宮金次郎"と呼ばれ信頼感を掴んだ。」
- → 印象に残るのは**B**。
- **相手がスーツを着ていない姿まで想像できて「この子はこういう子なんだ！」と伝わった時**に強い印象が残る。

📝まだ視野を狭める必要はないと思う。一方でESの作成時間も限られてくると思うので、自分の会社を決める上での優先順位、業務内容、仕事の環境、収入面など、最低限の自分の嫌なことや望むものがあれば、これを整理した上で業界がバラバラでもいいので、条件に合った会社を中心にESをかけ進めてみる。

しっかり書く会社と、とりあえずざっと調べて回し書きでもいいので出してみる、というところを自分の中で住み分けることが大事だと思う。

- 出版コースに所属していて就活も出版業界をメインで見ているのですが、広告業界も両立していくことは可能でしょうか？
📝私は可能だと思います。私もウェブライターをやっていたので、出版会社を見たこともあるのですが、実際やってみると広告業界との相性が良かったので、先行は最後に広告業界に絞ってました。

例えば、自分の個性をうまくESに落とし込むという点では、出版も広告も同じだと思うので、自分が広告業界ならどのラインまでESを挑戦するかを、これも見極めながら進めていれば両立は可能だと思います。

- ただの会社ファンからその業界の強者になる方法
📝業界の強者になれるかはわからないが、会社のファンであることは悪くないので、その好きな気持ちをどうやったら自分が入ったら活躍できるか、世に発信できるかを考えることが一つの方法だと思う。

自分の強みやこれまでの経験からファンであるその会社に入ったらやりたいこと、できることっていうのを整理しておけば、唯一無二のエピソードができ上がってくると思うので、面接の時に聞いてくると思う。

### ES：志望動機
- ESが通らない理由
📝運もあるので、必ずしもこれが要因とは言えないが、自分の見せ方が定まっていない人、分かりづらい人は多いと思う。すごく綺麗な言葉で並べて書いていても、何千枚とESを見ている中で、面接官の人に刺さりにくい抽象的な表現のみになってしまうと、ESが通りにくくなってしまう。

なので、自分が面接までを想定して、ESで何を伝えたいか、どういうふうな人だというふうに見せたいかを考えた上で、エピソード選びや文章の構成の工夫をしていけば、少しは改善されるのかなと思います。

- 志望動機の作り方と、その会社でのビジョン設計の作り方
- 志望動機の伝え方（広告愛はあるものの動機が言語化できていない）
📝まずは広告会社でやりたいことや生きたいと思った理由を素直に現体験を抑えてみる上で、自分がどこに興味を持ったのか、仕組みを作ることなのか、課題解決なのか、誰かの魅力に光を当てる行為そのものに魅力を感じたのかを、自分自身が興味を持った要因を言語化していくことが志望動機のまず第一歩だと思う。

その上で会社でのビジョン設計に関しては、OB訪問で主なジョブローテーションの仕組みなどを聞いた後で、自分が配属された場合にまずはどのスキルを身につけたいか、難しければOB訪問に協力してくれた先輩の力も借りながらすり合わせていくことが必要かなと思う。

特に最終面接になってくると、その会社の入社意欲、入社した後この子は活躍できるのか、どのくらい入社後のイメージまで描けているのか、入りたい熱量を問われる確認されることが多いと思うので、しっかり本気で受けたいのであれば、美女設計までしておくのはいいと思う。

- what to sayの定め方（語りたいエピソードが多く「〇〇の子」と覚えてもらえない）
📝〇〇な子だと覚えてもらえるために一番わかりやすいエピソードは何かな、というキャラクター設定を上に置いた時のエピソードを決める順番でいけばいいかなと思う。

友達と話していると、そのエピソードをもっと聞きたいと深掘りされる、注目を集めやすいエピソードがあると思うので、まずはそれを自己紹介の場だったり早めに自分から出しておくことで、つかみが生まれると思う。

- 「やりたいこと」と「向いていること」が違う場合、どう整理すればいいか。
📝基本的にやりたいことをやるのがおすすめしますが、向いていること×やりたくないことの掛け合わせではなければ、自分が向いていることに対して、成果を早く発揮するチャンスだと思って一度向いていることを目指してみるのもいいと思います。仕事のモチベーションは、自分のやりたいことや将来、成し遂げたいことが先にあって、その上にピンを置いていくことが多いです。そのため、ちゃんと将来のやりたいことに向かうための今向いていることをやっているのか、関係性を整理してから選ぶようにしたほうがいいです。
