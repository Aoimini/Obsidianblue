# NotebookLM スライド作成 指示文 ＋ ページ構成（確認用）

---

## 📋 NotebookLMへの指示文（このままコピペ用）

以下の構成でプレゼンスライドを作成してください。就活生（広告業界志望）向けの説明＆Q&A講座です。

**全体ルール**
- 1スライド＝情報を詰め込みすぎず、口頭で補足する前提で「見出し＋キーワード」中心に。
- 強調したい言葉は太字。専門用語は噛み砕く。
- トーンはフランクで親しみやすく（堅い就活セミナーにしない）。

**説明パートのルール（第1部・第2部前半・第3部前半）**
- 「大見出し（#）ごとに1ページ」にまとめる。
- 各ページは、見出し＋要点の箇条書き（3〜6個）で構成。

**Q&Aパートのルール**
- 1ページに「設問を3個」載せる。
- 各設問の下に、回答を「補足」として2〜4行の箇条書きで添える（話す内容のメモ）。
- 設問は短く、補足は要点のみ。

# 第2部：業界・会社の話

## スライド5：広告代理店について
参考：[広告ビジネスモデル解説](https://kashika-20mile.com/dpro/articles/advertising-business-model/)

**① ビジネスモデル（どう稼ぐか）**
- 収益は2つ：メディアからの**コミッション（手数料）**＋クライアントからの**フィー（報酬）**
- 従来マス広告は**媒体費の15〜20%**を手数料に（＝枠を仕入れて売る）
- デジタルは工数に手数料が見合わず、**工数フィー／成果報酬**へ多様化（"枠売り"→"課題解決の対価"）

**② 代理店ごとの違い**
- **総合広告代理店**：全媒体を扱い企画〜制作まで一気通貫（電通・博報堂・ADK等）
- **専門広告代理店**：特定領域に特化（ネット・交通広告など）
- **ハウスエージェンシー**：特定事業会社の専属

# 第3部：就活に関する話

## スライド14：OB訪問
- **若手と中堅を見比べる**：若手＝案件への関わり方・領域を知る／中堅＝給与の上がり幅、キャリア・スキルの変化を見て**ロールモデル探し**
- **分からないことは正直に質問**し、相手の答えの**裏にある具体的エピソードを引き出す**
- 📝「なぜ広告か」も聞く。コンサル就活が増える中であえて広告を選んだ理由・キャリアビジョンを聞くと、強いエピソードがなくても受かった人もいて、自分の組み立ての参考になる

## スライド15：ES
- ESは「書類通過」のためでなく、**面接で話しやすくするため**に書く（面接から逆算して仕込む）
- 書き方フロー（例：挫折を30字で）
  1. 自分のキャラが伝わるエピソードを決める（例：選手→マネージャー）
  2. 一番ウケそうなシーンを選ぶ（例：マネになった経緯、審判資格を取った理由）
  3. どんな質問が来れば②を話せるか考える
  4. 質問したくなる/記憶に残る**パワーワード**を仕込む
- 強いガクチカは不要（GS田中渓さんも夜勤コンビニバイトの話で内定）
- **「自分の人間性を相手に納得させるところまでをデザインする」のがコツ**

## スライド16：志望動機
- 「人生の中に仕事がある」→ **自分の生き方・思想を志望動機にしていい**（嘘をつかなくていい）
- 「仕事を通じて○○に貢献」の型に無理にハメない。軸は**「何をしている時が一番活き活きするか」**
- 原体験を通した**一貫性**を持たせるキーワードを探す

## スライド17：ガクチカ
- 大事なのは**相手がイメージできるよう言語化できるか**。成果物ではなく「何を課題に感じ」「周りとどう関わったか」のプロセス
- **A（きれい・抽象）**：「試合に出られないが、誰より早く自主練し信頼を得てピンチバッターに」
- **B（具体・泥臭い）**：「自主練の動画を撮りSNSに毎日アップ、アドバイスを求め続け"脳筋二宮金次郎"と呼ばれ信頼を得た」
- → 残るのは**B**。相手がスーツを脱いだ姿まで想像でき「この子はこういう子だ」と伝わった時に強い印象が残る

## スライド18：面接
- 面接官が知りたいのは4つだけ＝**「人柄・能力・やりたいこと・熱意」**
- **雑談・簡潔の罠**：全部結論ファーストだと「朝何食べた？」「食パンです」レベルに。雑談でも**見せたい印象をどう伝えるか**
- **イメージブランディング**：初対面の印象を踏まえ見せ方を戦略設計。例「冷静そうに見えて実は分析の上で粘り強く働きかける戦略家」。面接後の人事メモにどう残したいかまで考える

## スライド19：就活Q&A ①（企業研究・業界選び）
**Q. 企業研究でどんな資料を見るべき？**
- 📝 収益内訳・経営戦略は**IR・投資家向け資料**。売上の数字は**四季報**＋AIで「なぜ売上を作れているか」を分析・リスト化
- 📝 中小企業の特色は、発信の多い**note**で志望職種の人の思いやメンバーの特徴を覗くのも◎

**Q. 広告に絞る？視野を広げる？ESが追いつかない…**
- 📝 まだ視野を狭めなくていい。ただ時間は有限なので、**業務内容・環境・収入など自分の最低条件**を整理し、業界バラバラでも条件に合う会社中心にESを進める
- 📝 「しっかり書く会社」と「ざっと調べて回し書きで出す会社」を住み分ける

**Q. 出版志望だが、広告業界と両立できる？**
- 📝 可能。私もWEBライター経験から出版会社も見たが、相性が良く最後は広告に絞った
- 📝 **個性をESに落とし込む点は出版も広告も同じ**。広告ならどこまで挑戦するか見極めれば両立できる

## スライド20：就活Q&A ②（業界選び・ES志望動機）
**Q. ただの会社ファンから、その業界の強者になる方法は？**
- 📝 ファンであることは悪くない。その**好きを「入社後どう活躍・発信に変えられるか」**に変換するのが一つの方法
- 📝 強み・経験から「入ったらやりたいこと・できること」を整理すれば**唯一無二のエピソード**になり面接で活きる

**Q. ESが通らない理由は？**
- 📝 運もあるが、**自分の見せ方が定まっていない人**は多い。綺麗な言葉でも抽象的だと数千枚の中で刺さらない
- 📝 面接まで想定し「何を伝えたいか・どんな人に見せたいか」からエピソード選び・構成を工夫すると改善する

**Q. 志望動機が言語化できない（広告愛はある）／ビジョン設計は？**
- 📝 まず原体験から、広告の何に惹かれたか（仕組み作り／課題解決／誰かに光を当てる行為）を言語化するのが第一歩
- 📝 ビジョン設計はOB訪問でジョブローテを聞き、配属後まず何のスキルを身につけたいかを擦り合わせる。最終面接で活躍イメージを問われるので描いておくと良い

## スライド21：就活Q&A ③（ES志望動機・自己分析）
**Q. what to sayの定め方（語りたい話が多く「〇〇の子」と覚えてもらえない）**
- 📝 「〇〇な子と覚えてもらうのに一番分かりやすいエピソードは？」と、**キャラ設定を先に置いてからエピソードを決める**
- 📝 友達に深掘りされる・注目されやすい話を、自己紹介など早めに自分から出すと「つかみ」になる

**Q. 「やりたいこと」と「向いていること」が違う時の整理は？**
- 📝 基本はやりたいこと優先。ただ「向いている×やりたくない」でなければ、**成果を早く出すチャンス**として向いていることを目指すのもアリ
- 📝 モチベは「将来やりたいこと」が土台。今やることがそこに向かっているか整理してから選ぶ

**Q. 「らしさ」は素直に書く？企業に寄せるべき？**
- 📝 **会社に寄せる必要はない**。なんとなく受けている人ほど寄せようとして不自然に見える
- 📝 自分らしさを言語化しエピソードで語れる人は、面接官目線ですぐ分かる

## スライド22：就活Q&A ④（ES自己分析・ガクチカ）
**Q. 広告が本当に向いているか自信がない**
- 📝 広告にも制作・PR・CM・デジタル運用など多様な側面がある
- 📝 **「自分は広告の何が向いていない/それでもやりたい理由は何か」**を言語化してあげる

**Q. 強みの見つけ方／エピソードに自信が持てない**
