# 1. 就活全般

## 面接・伝え方（質問が最多のテーマ）

**核メッセージ：「面接は会話。雑談でも自分の見せたい一面を渡しに行く場」**

- **何を聞かれるか**：面接官が知りたいのは結局**「人柄・能力・やりたいこと・熱意」の4つだけ**。設問は無限にあるように見えて、全部この4つのどれかを確かめにきている。だから「この質問はどれを見にきてるか」を考えれば外さない。
- **必勝法/コツ**：巷の「結論ファースト・簡潔に」を全部の質問でやると、回答が全部「青が好きですね」になって何も残らない。**簡潔に答えた後、必ず一歩具体に踏み込む**。雑談すら自己PRの場にする。
- **端的に・でも詳しく話せない人へ（喋りすぎ問題）**：「端的＝短い」ではなく「端的＝結論が先頭にある」。最初の一文で結論を置き、**その後に"濃い具体例を1つだけ"**足す。エピソードは数を減らして1つを深く（ラーメンのたとえ＝全部薄くより一口で旨いと伝わる濃さ）。
- **スムーズに核心を突く**：その場でうまい言葉を探すから詰まる。**「自分はこういう人間」という1本の軸を事前に持つ**と、どの質問も軸に引きつけて答えられる。
- **失敗してしまう/詰まる人へ**：丸暗記した回答は、深掘りされた瞬間に崩れる。暗記すべきは"文章"ではなく"エピソードの事実と感情"。事実さえ手元にあれば、どんな角度で聞かれても話せる。
- **挫折経験の選び方**：盛った苦労話は不要。**「その時どう感じ、どう動いたか」が自分らしいもの**を選ぶ。きれいな結末より、泥臭い過程の方が残る。
- **30分の一貫性が不安な人へ**：→ 下の「一貫性は作るな、正直に話せば生まれる」を参照。事前準備は"模範解答集"ではなく**"自分の取扱説明書（性格1行＋裏付けエピソード3つ）"を作ること**。

## 志望動機・自己分析・強み

**核メッセージ：「一貫性は作るものじゃない。正直に話していれば勝手に生まれる」**

- **志望動機の作り方/ビジョン設計**：「仕事を通じて社会に〇〇」の型に無理にハメない。**「人生の中に仕事がある」→ 自分の生き方・好きなことを動機にしていい**。軸は「何をしている時が一番活き活きするか」。
- **広告愛はあるが言語化できない／"〇〇の子"と覚えてもらえない（what to say）**：エピソードが多いのは強み。でも**面接官は1つしか覚えられない**。「自分を一言で言うと何の子か」を先に決め、全エピソードをその看板の証拠として並べる（＝ブランディング）。
- **「やりたいこと」と「向いていること」が違う**：両方を無理に一致させなくていい。**「やりたいこと＝モチベーションの源」「向いていること＝再現性のある強み」**と整理し、面接では「向いていること（強み）でやりたいことに近づく」と接続する。
- **「らしさ」は素直に書く？企業に寄せる？**：→ **素直に書く**。寄せた瞬間に深掘りで崩れる。ただし"志望業界の人と性格が近い人が最強"なので、しっかり自己分析すれば、自然と相性の良い業界に寄っていく（寄せるのではなく、選ぶ）。
- **広告が向いているか自信がない／本当に好きか不安**：「向いているか」は外から見ないと分からない部分が大きい。**自信は分析からでなく、行動（OB訪問・インターン・人に話す）から後付けで来る**。今ない自信を机上で作ろうとしない。
- **強みの見つけ方／どんな人に惹かれるか**：自分では強みは見えない。**人に「私のすごいところって何？」と聞く**、または「自分が無意識にやっていて、人から感謝/驚かれること」を集める。惹かれる人＝自分が伸ばしたい価値観の鏡。
- **自己分析の方法**：過去の意思決定（部活・進路・人間関係）を「なぜそう選んだか」で掘る。共通する判断基準が"あなたの軸"。【※自分がやって効いた自己分析法を1つ実例で】
- **エピソードに自信が持てない**：→ ガクチカの章へ。**「強いエピソード」より「ありのままを言語化できているか」が評価される**。

## 企業研究・業界選び

- **どんな資料を見るべきか**：①各社の中期経営計画・統合報告書（IR）→ 会社が"どこへ行きたいか"が分かる、②採用サイトの社員インタビュー → "どんな人がいるか"、③その会社が最近出したリリース・受賞作 → "今の旗印"。【※ADKでおすすめの一次資料を具体名で】
- **広告に絞るか、視野を広げるか**：**前半は広げ、後半は絞る**のが現実的。ESが追いつかないのは当然なので、「軸（＝自分が大事にする価値）」を先に決めると、軸の通る数社に自然と絞れてESも使い回せる。
- **出版志望と広告の両立**：両立は可能。むしろ**「コンテンツで人の心を動かしたい」という共通の軸**で語れば、出版経験が広告ESでも武器になる。"二兎"ではなく"一つの軸の二つの出口"として語る。
- **ただのファン→業界の強者になる／ESが通らない理由**：ファンは「好き」を語り、通る人は「**その会社の課題と自分がどう役立つか**」を語る。ESが通らない最大要因は、抽象的なきれいごと（意欲・貢献）で埋まっていて"あなたが見えない"こと。

## ガクチカ・漠然とした不安

**核メッセージ：「強いガクチカは要らない。ありのままを言語化できる人が個性的に見える」**

- **強い/特別なガクチカがない人へ**：面接官は実績の大きさを見ていない。「**1つの出来事をどう感じ、どう取り組み、周りとどう関わったか**」のオリジナリティを見ている。日常レベルのエピソードでも、感じ方が言語化できていれば刺さる（野球部A/Bの例：きれいな"満足度向上"より、泥臭い"脳筋論文野郎"が残る）。
- **埋もれる不安**：差別化＝派手なネタではなく、**具体の解像度**。「相手がスーツを脱いだ姿が浮かぶ」レベルまで細部を話せれば埋もれない。
- **採用で一番重視すること**：【※自分の答えを一言で】（講座の主張に沿うなら→「**完璧さより、ダイヤになりそうな粗削りさ＝伸びしろと正直さ**」）。
- **漠然とした不安／SNSの情報過多**：将来が"決まる"と思うから怖い。実際は**就職は決定ではなく一手目**。情報は集めるほど不安が増えるので、**信頼できる人2〜3人に絞る**（＝この講座やOB訪問の使い方）。
- **クライアントの中に入ってチームで動く仕事**：それはまさに広告代理店/事業会社の伴走支援の面白さ。【※自分のクライアントワーク実体験（デジタル領域の伴走）で具体化】合う会社の見分け方＝「事業の上流から入れるか」「裁量が早いか」。

# 2. 広告業界について

## 業界の未来・AI

**核メッセージ：「広告業界の軸は『クライアントの課題解決』。手段が広告からマーケ・事業へ広がっている」**

- **質問者の認識「課題解決が軸、手段がコンサル/マーケ寄りに」は正しいか** → **基本的に正しい**。広告（4マス）はあくまで手段の一つになり、上流の事業課題から関わる方向にシフトしている。
- **広告業界の未来/10年後**：作る対象が"広告"から"事業成長そのもの"へ。「広告会社」から「成長支援会社」への移行。【※自分の現場での変化実感を1つ】
- **生成AIで若手に求められる力**：作業（制作・調査）はAIに寄る分、**「何を作るかを決める力＝課題設定・人を動かす企画・クライアントとの関係構築」**の比重が上がる。
- **AIに仕事を奪われている実感はあるか**：→ 正直に。【※実体験】（型：「単純作業は奪われ始めている。でも"奪われた時間"を上流に使えるので、むしろ面白い仕事の比率は上がっている」）。
- **総合代理店だけが持つ価値（インハウス化が進む中で）**：①**多数のクライアント/メディアを横断する知見**、②**大規模をまとめきる総合力（メディア・制作・データを一気通貫）**、③**第三者だからこそ言える客観性**。インハウスには溜まらないもの。
- **ポートフォリオの作り方（制作物より事業貢献の時代）**：「きれいな成果物」より**「どんな課題を、どう捉え、なぜその手を打ったか」のプロセス**を見せる。結果の数字＋思考過程をセットで。
- **4マスへの逆戻りはあるか**：全面回帰はない。ただ**テレビ等のマス×デジタルの組み合わせ**は残り、信頼性・到達力の文脈でマスの価値は再評価される局面がある。

## 業界の魅力・特徴・違い

- **なぜ広告を選んだか／やりがい・難しさ・伸び/下がり**：【※実体験で。型：やりがい＝自分の企画で人や世の中が動く／難しさ＝正解がなく泥臭い調整が多い／伸び＝デジタル・事業支援／課題＝従来型マスの単価】
- **広告にしかできないこと**：「**他人（クライアント）の想いを翻訳して、まだ知らない人に届け、行動を変える**」こと。自社商品を売るのではなく"他者の魅力を世に出す黒子"。【※自分の言葉に】
- **代理店の広告 vs 事業会社が自社で作る広告の違い**：事業会社は自社理解が深い／代理店は**客観性・多事例の引き出し・専門分業の総合力**。
- **芸大卒でなくても作れるか** → **作れる**。手を動かす制作だけが広告制作ではない。企画・戦略・進行も"作る"。むしろ非芸大の視点が強みになる職種が多い。
- **総合代理店から見たWeb専門代理店**：敵ではなく役割分担。専門代理店＝特定領域の深さ／総合＝統合の広さ。【※自分の見解を率直に】
- **「テレビ広告をやりたい」はマイナスか** → **理由があればマイナスにならない**。むしろ"なぜテレビか"を自分の原体験で語れれば一貫性として評価される。NGなのは「なんとなく憧れ」。
- **メリット/デメリット・一番タフな部分・働く人の雰囲気**：【※全部実体験で。型：タフ＝板挟み/短納期/正解のなさ。雰囲気＝好奇心旺盛で人好き、が多い→ただし"好奇心旺盛"で止めず具体エピソードまで話す（OB訪問の章の自戒）】

## 求められる人材・働き方

- **知識ゼロでも大丈夫か／求める人材**：広告知識は入社後でつく。求められるのは**好奇心・人を巻き込む力・素直さ**。【※自分が現場で「この人いいな」と思う人物像を実例で】
- **ワークライフバランスの実態**：【※正直に。盛らない方が信頼される】（型：繁閑の波はある。昔より働き方は改善。部署/時期による）。
- **難易度が高い中でどう内定を取るか**：→ 1章の面接・ESに全部つながる。「**面接から逆算したES＋ブランディング**」。
