ExitとしてのIPO
▼企業視点のメリット ・資金調達がしやすくなる → 上場後は市場から継続的に資金調達可能 ・信用、知名度が一気に向上 → 採用/営業/パートナー獲得が楽になる ・M&Aの選択肢が広がる → 自社株を使った買収（株式対価）が可能 ・経営管理体制が強化される → ガバナンス/内部統制が整う ▼企業視点のデメリット ・ディスクロージャー負担が大きい → 情報開示義務で戦略が見えやすくなる ・短期的な市場評価に左右される → 四半期ごとの業績プレッシャー ・経営の自由度が下がる → 株主、市場の意向を強く意識する必要 ・買収リスク → 株式が分散し、敵対的買収の可能性 ・維持コストが高い → 上場維持費、監査、IRコストなど ▼株主視点のメリット ・流動性が生まれる（現金化しやすい）→ 市場でいつでも売却できる ・株価が可視化される → 企業価値が明確になり、資産価値が上がる ▼意思決定で考えるべきポイント ・株主の流動性ニーズ、社員のモチベーション、経営者の志 ・Purpose（目的）Mission / Vision / Valueとの整合 ・Strategy（戦略）競争環境、IPO以外のExit（M&Aなど）、成長ストーリーとの相性など
