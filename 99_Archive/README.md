# 99_Archive の使い方

**「消すか迷ったらここに入れる」箱。**削除の意思決定を後回しにするための場所です。

- ここに入れたものはヴォルトの検索・グラフには出てきますが、現役フォルダを汚しません。
- 四半期に一度(3月・6月・9月・12月末)、中身を見て「3ヶ月間一度も開かなかったもの」をまとめて削除。
- git履歴が残っているので、テキスト系は消しても復元できます。
